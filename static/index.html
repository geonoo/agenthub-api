Setup

Claude · GPT 연동 따라하기

기존 설정(preferences 등)은 그대로 두고, mcpServers만 추가하면 됩니다. API 키는 .env의 API_KEY를 사용하세요.

Claude Desktop

MCP
  1. 1 Claude Desktop → Settings → Developer → Edit Config 로 claude_desktop_config.json을 엽니다.
  2. 2 이미 있는 preferences / coworkUserFilesPath는 지우지 말고, 맨 위에 mcpServers 블록만 추가합니다.
  3. 3 YOUR_API_KEY를 실제 키로 바꾼 뒤 저장 → Claude 완전 종료 후 재실행.
  4. 4 새 채팅에서 도구 아이콘을 확인하고 물어보세요: 「삼성전자 최신 공시랑 뉴스 정리해줘」

추가할 JSON (기존 설정과 합친 예시)

{
  "mcpServers": {
    "agenthub": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://api.agenthub.co.kr/mcp/sse",
        "--header",
        "X-API-KEY: YOUR_API_KEY"
      ]
    }
  },
  "coworkUserFilesPath": "/Users/mailplug/Claude",
  "preferences": { "...기존 preferences 그대로..." }
}

Node.js가 필요합니다 (npx). macOS 경로 예: ~/Library/Application Support/Claude/claude_desktop_config.json

ChatGPT (Custom GPT)

Actions
  1. 1 ChatGPT → Explore GPTs → Create a GPT → Configure → Actions
  2. 2 Authentication: API Key · Header 이름 X-API-KEY · 값에 AgentHub API 키 입력
  3. 3 Schema에 OpenAPI URL을 Import 하거나 아래 스키마를 붙여넣습니다.
  4. 4 저장 후 GPT에게: 「삼성전자 최신 공시랑 뉴스 정리해줘」

OpenAPI Import URL

https://api.agenthub.co.kr/openapi.json

권장 Instructions (GPT 프롬프트)

당신은 한국 금융 데이터 어시스턴트입니다.
종목 공시는 get_company_disclosures(DART), 뉴스는 get_finance_news Actions를 호출하세요.
HTML이 아닌 Clean Markdown/JSON만 요약에 사용하고, 출처(접수번호·기사 제목)를 함께 적으세요.

사용 엔드포인트: /api/v1/dart/company-disclosures, /api/v1/finance/news

팁: 지금 가진 설정 파일에 mcpServers가 없다면, 파일 맨 위에만 추가하면 됩니다. preferences 블록은 그대로 두세요. 전체가 이렇게 됩니다:

완성본 골격

{
  "mcpServers": {
    "agenthub": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://api.agenthub.co.kr/mcp/sse",
        "--header",
        "X-API-KEY: YOUR_API_KEY"
      ]
    }
  },
  "coworkUserFilesPath": "/Users/mailplug/Claude",
  "preferences": {
    "sidebarMode": "chat"
  }
}
